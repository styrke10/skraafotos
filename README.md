# Skråfotos

QGIS 3/4 plugin til opslag på Dataforsyningens Skråfotos.

## Formål

Plugin'et letter opslag i Dataforsyningens Skråfotos ved at give mulighed for direkte at udpege det ønskede sted og retning for det skråfoto, der skal vises.

## Anvendelse

Efter installation af plugin'et tilføjes en knap i værktøjsbjælken. Knappen har samme ikon som plugin'et i QGIS Plugin Repository.

Ved aktivering af knappen vises første gange (og indtil man disabler dette) en lille dialogboks, hvor plugin'ets virkemåde illustreres.

Luk denne dialog og træk herefter en streg i kortet, som angiver retning på skråfotoet (ét af de 4 verdenshjørner) samt slutpunktet, som er det punkt, der skal være centrum i skråfotoet. Hvis den tegnede linje ikke matcher et verdenshjørne præcist, vælges den nærmeste herpå.

Dataforsyningens Skråfotos åbner nu i default browser'en med det valgte punkt og retning som hovedbillede.
